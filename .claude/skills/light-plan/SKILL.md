# Light-plan (Claude Code wrapper)

Read and follow `.cursor/skills/light-plan/SKILL.md`. That file is the procedure of record, including the release table in §Release. This page lists only what changes in Claude Code. Do not copy the procedure here.

## Claude Code adaptations

| In the Cursor source | In Claude Code |
|----------------------|----------------|
| §Run to completion: do not end the turn at step boundaries | Same intent. When a turn must end while CI or Pre-UAT is still running, park with `Parked on CI for <PR>; resuming on event.` and resume on the subscription event or completion notice. Wait with `run_in_background`, never `sleep`. |
| §Recovery: engine relaunch (`v2:launch` comment, pipeline monitor) | Cursor-only. If a run stops here, resume by typing `continue light-plan #<issue>`. |
| §Branches: `cursor/<slug>-integration-<xxxx>`, `cursor/<slug>-dev` | Keep the `cursor/` prefix for programme branches. The integration ruleset and scripts match `cursor/*-integration-*`, so a `claude/` name would not match. This session's own `claude/…` branch is not a programme branch. |
| §Release: read and follow `/babysit-plus` (policy row 6) | Read `.cursor/skills/babysit-plus/SKILL.md` and follow it; invoke via Skill tool when enabled. |
| §Stop and ask: start the final message with `Need owner decision:` | Same wording. The relaunch monitor that reads it is Cursor-only; the owner still sees what is needed. |
| `gh pr merge <url> --merge`, `gh pr ready` | Return 403 here (GraphQL). Use the REST and CCR commands in the `babysit` wrapper §GitHub in Claude Code sessions. |
| `babysit_pr_reviews.js wait` / `gate` (light merge step 2) | Run unchanged with `scripts/ccr-bin` first on `PATH` (`babysit` wrapper §Babysit scripts). |
| Comments on the tracking issue | End each one with `_Generated by [Claude Code](https://claude.ai/code)_`. |

Gates, the review gate and the "do not close the tracking issue" rule are unchanged. Pre-UAT runs asynchronously in Actions after release merge (not an in-session babysit-uat watch).
