# E2E debug (Claude Code wrapper)

Read and follow `.cursor/skills/e2e-debug/SKILL.md`. That file is the procedure of record, including the Phase 0 preflight, which runs first. This page lists only what changes in Claude Code. Do not copy the procedure here.

## Claude Code adaptations

| In the Cursor source | In Claude Code |
|----------------------|----------------|
| §Phase 5: Task subagents (`generalPurpose`), `composer-2.5` only | Use the Agent tool only when you ask for parallel workers. The default is one orchestrator working sequentially. |
| §Phase 5–6: separate Cloud Agent pod per shard (`babysit_uat_run_shard_isolated.sh`) | No separate pods here. Run shards one at a time with `./scripts/babysit_uat_run_shard.sh <N>` on this container. |
| §Phase 6: `npx playwright install chromium --with-deps` (also run by `babysit_uat_bootstrap_stack.sh` and `e2e/scripts/run-local.sh`) | Let the repo scripts run their install step as written. This PR does not change them. If it fails or is redundant here, use the preinstalled `/opt/pw-browsers/chromium` (`executablePath`) for ad-hoc runs, and say which browser you used. If the project pins another `@playwright/test`, use that `executablePath` as well. |
| Playwright runs | Add `--trace off` unless a trace is needed. For a debug run, use `--trace on` on that one test. |
| §Phase 2: `gh run download … -D /tmp/preuat-artifacts` | Download to the session scratchpad, not `/tmp`. |
| §Phase 8 step 1: `ManagePullRequest update_pr` with `draft: false` | `gh api -X POST repos/AgathaTrack/AgathaTrack/pulls/<n>/ccr/ready_for_review` (`gh pr ready` returns 403 here). |
| §Phase 8 step 4: immediately invoke `/babysit-uat` | Invoke the `babysit-uat` skill with the Skill tool, in this session. |
| "Subscribe to CI" with `cursor-subscriptions` on `pre-uat-e2e.yml` | `cursor-subscriptions` is Cursor-only. Watch the run with `run_in_background`, or subscribe to PR activity for the remedial PR. |
| Comments on the control issue or PR | End each one with `_Generated by [Claude Code](https://claude.ai/code)_`. |

The preflight, claim and release steps, the shard-ownership rules and the round cap are unchanged.
