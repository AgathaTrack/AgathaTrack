# Babysit+ (Claude Code wrapper)

Read and follow `.cursor/skills/babysit-plus/SKILL.md`. That file is the procedure of record, including the mandatory pre-PR critical review. This page lists only what changes in Claude Code. Do not copy the procedure here.

## Claude Code adaptations

| In the Cursor source | In Claude Code |
|----------------------|----------------|
| §Model and §0b step 1: `composer-2.5` only; switch model or spawn a fresh cloud agent | Not applicable. Ignore these steps and keep the session's model. The execute-plan rule that v2 workers never merge still applies. |
| `ManagePullRequest create_pr` / `update_pr` (§Inputs, §Pre-PR) | Use the REST commands in the `babysit` wrapper §GitHub in Claude Code sessions. `gh pr create` returns 403 here. Fill the headings of `.github/pull_request_template.md`. Do not put a model name in the title or body. |
| §Pre-PR 5: `/canonical-docs sync` | Use the `/canonical-docs` wrapper. |
| Waiting: `gh pr checks <url> --watch` (§5), `babysit_pr_reviews.js wait` (§0b) | `gh pr checks` returns 403 here. Poll the check-runs command in the `babysit` wrapper instead, with `run_in_background` and a completion notice, or subscribe with `subscribe_pr_activity`. Never `sleep` or one-shot poll. If the turn must end first, park with `Parked on CI for <PR>; resuming on event.` Run `wait` through the `gh` wrapper below. |
| `babysit_sync_base.sh` (§0–§5 sync, §7) and the §7 review gate `babysit_pr_reviews.js gate` | Run them unchanged with `scripts/ccr-bin` first on `PATH` (`babysit` wrapper §Babysit scripts). Exit codes are the policy's. Exit `1` is an error: never merge on it. |
| Spawning agents (fresh cloud agent, `/spawn-sprint-agents`) | Not used. Start subagents only when you ask for them. |
| `/autopilot` handoff | Not available here. |
| Comments and replies | End each one with `_Generated by [Claude Code](https://claude.ai/code)_`. |

**Tokens:** the `scripts/babysit_*` and `github_issue_workflow.js` commands need a GitHub token in the environment (`GH_TOKEN`, or `PAWPET_CLAUDE_TOKEN` where the repo uses it). Do not rely on `GITHUB_TOKEN`.

Merge gates, the review gate, debt-issue rules and escalation are unchanged. Related wrappers: `/babysit`, `/babysit-uat`, `/pre-push-verify`, `/canonical-docs`, `/execute-plan`.
