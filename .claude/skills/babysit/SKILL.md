# Babysit (Claude Code wrapper)

Read and follow `.cursor/skills/babysit/SKILL.md`. That file is the procedure of record. This page lists only what changes in Claude Code. Do not copy the procedure here.

## Claude Code adaptations

| In the Cursor source | In Claude Code |
|----------------------|----------------|
| §Model: `composer-2.5` only, switch model | Not applicable. Keep the session's model. |
| §Cursor cloud handoff: built-in `/autopilot` | Not available here. Run the in-session steps 1–9 directly. |
| `gh pr view`, `gh pr checks`, `gh pr ready`, `gh pr merge`, `gh pr create` | Return 403 in Claude Code sessions (GitHub GraphQL is blocked). Use the REST and CCR commands in §GitHub in Claude Code sessions below. |
| Waiting on CI or review (`gh pr checks --watch`, `babysit_pr_reviews.js wait`) | Run with `run_in_background` and wait for the completion notice, or subscribe with `subscribe_pr_activity`. Never `sleep`. If the turn must end first, park with `Parked on CI for <PR>; resuming on event.` |
| Comments and replies | End each one with `_Generated by [Claude Code](https://claude.ai/code)_`. |

**Tokens:** the `scripts/babysit_*` scripts need a GitHub token in the environment (`GH_TOKEN`, or `PAWPET_CLAUDE_TOKEN` where the repo uses it). Do not rely on `GITHUB_TOKEN`.

## GitHub in Claude Code sessions

`gh pr …` subcommands and the `scripts/babysit_sync_base.sh` and `scripts/babysit_pr_reviews.js` scripts call GraphQL, which this session cannot reach. They fail with 403. A script error is never a clean result: do not read it as "up to date" or "no threads". Use these instead (`<n>` is the PR number, `<sha>` the head SHA):

| Need | Command |
|------|---------|
| PR state, `mergeable`, draft | `gh api repos/AgathaTrack/AgathaTrack/pulls/<n>` |
| CI status | `gh api repos/AgathaTrack/AgathaTrack/commits/<sha>/check-runs` |
| Create PR | `gh api repos/AgathaTrack/AgathaTrack/pulls -f title=… -f head=… -f base=main -f body=…` (add `-F draft=true` for a draft) |
| Ready for review | `gh api -X POST repos/AgathaTrack/AgathaTrack/pulls/<n>/ccr/ready_for_review` |
| Review threads (unresolved) | `gh api repos/AgathaTrack/AgathaTrack/pulls/<n>/ccr/review_threads` |
| Reply to a review comment | `gh api -X POST repos/AgathaTrack/AgathaTrack/pulls/<n>/comments/<comment_id>/replies -f body=…` |
| Resolve a thread | `gh api -X POST repos/AgathaTrack/AgathaTrack/pulls/<n>/ccr/comments/<comment_id>/resolve` |
| Squash merge | `gh api -X PUT repos/AgathaTrack/AgathaTrack/pulls/<n>/merge -f merge_method=squash` |

If the policy's review gate cannot run here, say so on the PR and to the owner. Do not merge on the strength of a manual check without the owner's go-ahead.

Escalation, the merge rules and the policy links are unchanged. Related wrappers: `/babysit-plus`, `/babysit-uat`, `/pre-push-verify`, `/canonical-docs`.
